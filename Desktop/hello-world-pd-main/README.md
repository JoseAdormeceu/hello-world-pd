## Regra de commit message

Formato obrigatório: `<tipo>: <descrição>`

Tipos permitidos: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

✅ Exemplo válido: `feat: add hello world page`
❌ Exemplo inválido: `updated stuff`
